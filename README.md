## 🧰 Sample Python Tool (Educational Port Scanner)

```python
# Simple Port Scanner (For Educational Use Only)

import socket

target = input("Enter Target IP: ")
ports = range(1, 1025)

print(f"\nScanning {target}...\n")

for port in ports:
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(0.5)
    result = s.connect_ex((target, port))
    if result == 0:
        print(f"[+] Port {port} is OPEN")
    s.close()
```
